# smart-task-manager
A simple web-based Task Manager built with vanilla JavaScript, HTML, and CSS. Demonstrates key JS concepts like DOM, events, classes, modules, async/await, and localStorage.


Smart Task Manager
A simple and interactive web-based task management app built with vanilla JavaScript, HTML, and CSS.
It demonstrates core JavaScript concepts including:

Identifiers and Data Types (Primitive & Non-Primitive)

Conditional Statements and Loops

Functions (Arrow, Nested, Parameterized)

Object-Oriented Programming (Classes & Objects)

DOM Manipulation and Event Handling

Variable Scopes and Built-in Functions

Modules (Import/Export)

Array Methods and Destructuring

Asynchronous Programming with Fetch API (Async/Await, Promises)

Local Storage for persistent task management
